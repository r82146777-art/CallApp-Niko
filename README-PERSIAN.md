# پروژه CallApp — راهنمای ساخت APK با گوشی

این پروژه یک برنامه اندروید با Kotlin و Android Gradle Plugin است. برای ساخت APK به ویندوز نیاز نیست؛ GitHub Actions ساخت را روی سرورهای لینوکسی GitHub انجام می‌دهد.

## نسخه ۱.۱ (تکمیل‌شده)

- کلاس‌های ناقص `MmsReceiver`، `RespondService` و `SmsStatusReceiver` اضافه شد تا Manifest کامل باشد.
- منابع دسترسی‌پذیری (strings، colors، themes، contentDescription) بهبود یافت.
- آیکون ساده و تم مناسب نابینایان/کم‌بینایان اضافه شد.
- نسخه به ۱.۱ و versionCode=۲ ارتقا یافت.

## روش ساخت با گوشی

1. وارد https://github.com/r82146777-art/CallApp-Niko شوید.
2. وارد زبانه Actions شوید و اجرای «ساخت APK اندروید» را باز کنید.
3. پس از سبز شدن وضعیت، فایل `CallApp-apk` را دانلود کنید.

## مشخصات فنی

- زبان: Kotlin
- شناسه برنامه: `com.example.callapp`
- حداقل Android: API 29
- هدف: Android API 34
- نسخه: 1.1 (versionCode 2)
